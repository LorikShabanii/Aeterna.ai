# Aeterna.ai
Aeterna: A Zero-Knowledge Digital Legacy Vault &amp; Dead Man’s Switch. Securely transfer encrypted assets, credentials, and final messages to heirs with privacy-first client-side encryption.

See [CLAUDE.md](./CLAUDE.md) for the full product brief and build order.

## Getting started

```bash
bun install
bun --bun run dev
```

Copy `.env.example` to `.env` and fill in your Supabase project URL and anon key before running the app — see `supabase/README.md` for how to apply the database schema.
